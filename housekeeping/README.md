# Housekeeping Utilities

This directory contains utility scripts for document conversion and processing.

## Files

### `convert_analysis_to_pdf.py` (Nov 19, 2.3K)
Converts analysis documents to PDF format.

### `convert_to_html.py` (Nov 19, 2.3K)
Converts documents to HTML format for web viewing.

### `convert_pdf_to_text.py` (Nov 19, 1.5K)
Extracts text content from PDF files for analysis.

### `download_and_convert_arxiv.py` (1.8K)
Downloads and converts arXiv papers for reference.

## Usage

These are utility scripts for documentation and paper processing tasks. They are not core to the training/evaluation pipeline but are useful for:
- Converting research papers to readable formats
- Generating reports from analysis documents
- Processing reference materials

## Core Scripts

For core training and evaluation functionality, see scripts in the root directory:
- Training: `train_ddp.py`
- Testing: `test_*.py`
- Benchmarking: `paper_training_efficiency_benchmark.py`, `evaluate_paper_benchmarks.py`
