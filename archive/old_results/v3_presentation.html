Model Architecture

Core Innovations

🔹 Ternary Weight Quantization (1.58-bit)

Weights quantized to {-1, 0, 1} instead of full precision

🔹 8-bit Activation Quantization

Per-token quantization to [-128, 127] range

🔹 HGRN Attention

Hierarchical Gated Recurrent Network replaces standard softmax attention

🔹 Fused Triton Kernels

LayerNorm + Linear + Quantization combined in single kernel

⚠️ Implementation Note

Triton Autotuning: DISABLED

Due to Triton 2.2+ compatibility issues, autotuning was disabled. Kernels run with fixed default configurations (BLOCK_SIZE=64, num_warps=4) instead of optimized parameters.

Why The Poor Results?

Implementation Issues

  • Autotuning disabled - kernels not optimized for hardware
  • Only 2 of 4 GPUs working - batch_size=2 < num_GPUs=4
  • Batch size too small - effective batch=4 vs paper's 256
  • Sequential HGRN attention - processes tokens one-by-one instead of parallel

Hardware Mismatch

  • Paper used A100 - 2 TB/s memory bandwidth
  • We used A10G - 600 GB/s bandwidth
  • MatMul-free is memory-bandwidth bound
  • Pythia heavily optimized (FlashAttention, FP16, etc.)

📊 Conclusion

Our implementation with broken optimizations cannot compete with a highly-polished baseline (Pythia). The architecture might work with:

  • Autotuning re-enabled (10-20% improvement expected)
  • All 4 GPUs utilized (2x speedup expected)
  • Larger batch sizes (64-256 to amortize overhead)
  • Proper hardware (A100 with high memory bandwidth)

Next step: V4 training with 370M params, seq_len=1024, and proper GPU utilization to validate if the approach works when correctly implemented.
